How I work

  1. Understand it

    Read the problem and the existing code before touching anything. Most bugs have a boring cause.

  2. Build it properly

    Small, readable pieces I can explain later. AI tools speed up the first draft; I read, test and fix what they produce.

  3. Break it, then polish it

    Test on a real phone, fix what breaks, then tune the details until it feels right.
